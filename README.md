# CodeAlpha - Stock Portfolio Tracker

## Overview

This project was developed as part of the Python Programming Internship at CodeAlpha.

The Stock Portfolio Tracker allows users to enter stock symbols and quantities, calculates the total investment value using predefined stock prices, and generates a portfolio summary. The program also saves the investment details to a text file for future reference.

## Features

* Add multiple stocks to a portfolio
* Uses predefined stock prices
* Calculates individual and total investment values
* Displays a portfolio summary
* Saves results to a text file
* Simple console-based interface

## Technologies Used

* Python 3

## Concepts Used

* Dictionaries
* Loops
* Conditional Statements
* User Input Handling
* File Handling
* Basic Arithmetic Operations

## How to Run

1. Clone the repository:

   ```bash
   git clone <repository-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd CodeAlpha_StockPortfolioTracker
   ```

3. Run the program:

   ```bash
   python stock_portfolio_tracker.py
   ```
